# مجلد تصديرات الفيغما

ضع هنا الأيقونات والصور المصدَّرة من الفيغما **بالأسماء أدناه حرفيًا**، ثم أعد
تشغيل التطبيق (`flutter run`) — تظهر تلقائيًا مكان البدائل المؤقتة. ما دام
الملف غائبًا يبقى البديل الحالي، فلا شيء ينكسر.

## الصيغة
- **الأفضل SVG متجهة نقية**: صدّر طبقة الرسم المتجه نفسها، لا إطارًا بداخله
  صورة — تصدير إطارٍ صورتُه PNG يولّد SVG ملفوفة (`<pattern>` + `<image>`)
  **تظهر مربعًا أبيض** في التطبيق.
- إن لم يتيسر: **PNG** بنفس الاسم (مثل `icon-filter.png`) — مقبولة، ويفضل
  تصدير 4x للوضوح. الكود يجرّب `.svg` ثم `.png`.
- الأيقونات المعلَّمة «تُصبغ» يجب أن تكون أحادية اللون (أي لون — يستبدل
  برمجيًا بلون الموضع)؛ والمعلَّمة «كما هي» تُعرض بألوانها.
